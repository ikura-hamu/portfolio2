CODE BLUE 2026 のチケットをもらいました。セキュリティは詳しくないですが、チケットの値段を調べるととんでもなかったので、これは行くしかないと思い行ってきました。

自分が聴いた話の中で面白かったものを書きます。

## 1 日目

### [Pwn2Own Berlin 2026 $20,000] Agent2Shell: Your AI Coding Agent Already Ran the Attacker's Code

AI エージェントを動かすアプリ(ChatGPT Desktopなど)の脆弱性調査に関するセッションです。Git の設定とかを通して、ディレクトリを開くだけでコード実行ができていることがあったそうです。初めてディレクトリを開いたときに出る「このフォルダを信頼する」は大事なんだなと思いましたが、それを押す人間がダメダメだったら意味ないので、頑張らないといけないなと思いました。
また、OpenAI や Anthropic のエンジニアはおそらく最新の LLM をほぼ無限に使えると思うのですが、それでも脆弱性を埋め込んでしまうんだなと思いました。一方で攻撃側はエージェントで脆弱性を見つけられる訳で、防御側が不利すぎるなと思いました。

### Threat Intelligence との付き合い方

パナソニックの IoT 製品のセキュリティに関するお話でした。
IoT機器はサーバーなどと異なり企業から離れたところで動いているため、調査を行うことが難しいです。そこで、意図的にセキュリティレベルを下げたハニーポッドを作って攻撃データを集めているそうです。ショールームになっていて、いろいろ光っていてかっこよかったです。見に行きたい。
空いてるポートが多いほど攻撃を受けやすいとかの直感的に正しそうなものがデータで出てきたりして、説得力があるのは大事だと思いました。

### Behind Endless Vulnerability Headlines, Malicious Packages Keep Coming: Software Supply Chain Attacks Seen Through 19 Million Package Versions

直近話題が多く、僕の活動にも近い領域で起きている、パッケージ汚染、サプライチェーン攻撃に関するお話です。
Flatt Security は npm や PyPI などに公開されているパッケージを全部調べて、悪性パッケージを検出しており、検査したパッケージの 0.2% が悪性と判定されたそうです。かなり多い気がします。そのうち大きな話題になるのはごく一部で、知らないところでいろいろ起きてるんだなと思いました。
攻撃側の工夫も説明されており、手が込んでるなと思いました。AI が間違って提案しそうなパッケージ名を使う「Slop Squatting」や、クレデンシャルを窃取して連鎖的に悪性パッケージを公開するワーム型の攻撃などです。以前の攻撃では、トークンが無効化されたのが確認されたらホームディレクトリを削除するようなマルウェアが配布されたりしたようです。怖すぎる。

### Threat Intelligence超入門

セッションで話を聴いたパナソニックのハニーポッドのデータを分析するワークショップです。データの中身は公開できないことになっているので詳しく書けないのですが、いろんなタイプの攻撃が来ているのが見えて面白かったです。下手にインターネットにデバイスを繋がないようにしようと思いました。

## 2 日目

### Five Years of GitHub Monitoring: Unveiling the Lifecycle of Malicious and For-Sale PoCs

GitHub 上で公開されている、脆弱性の PoC に関する調査分析結果の話です。
偽の PoC や PoC の販売などが行われているそうです。
偽の PoC はマルウェアをダウンロードさせたり外部に情報を送信したりします。正規の PoC をちょっとだけ変えて配布されたりもしているそうです。
PoC の販売については、GitHub 上でリンクを公開して売っており、年々値段が上がっているそうです。物価高の影響がここにも来てるのかと思いましたが、流石に関係ないかな。ファイル数が多かったりデモ動画が付いてたりと販売側の手が掛かってる場合には値段が上がりがちらしいです。

### Biohacking Village

医療機器を分解できるブースがあったのでやってみました。指で血中酸素濃度を測るパルスオキシメーターを分解しました。普段ハードウェアは全くいじっていないので中身はよく分かりませんでしたが、基板や配線が繋がってるのが見えて面白かったです。慣れてる人はデバッグ用の空いてるところに配線を繋いで動かしたりするらしいです。

### Too Close to the Metal: Attacking GPU Neo-Clouds from the Inside and Out

需要が上がっている GPU レンタルサーバーへの攻撃についてです。
いくつかの攻撃面に関する話がありましたが、BMC に関する内容が印象に残っています。というのは、ちょっと前に研究室サーバーのメンテナンスで BMC を触る機会があったからです。BMC を操作する方法として、古い IPMI と新しい Redfish があり、IPMI はプロトコルそのものに脆弱性があって推奨されていません。僕が BMC を操作したときは LLM の言うことに従って IPMI を使った気がするので、正しい知識がないと LLM の言うことを判断できないなと思いました。
BMC は OS とは別で動いているため、レンタル期間が終わっても BMC はそのままになり、提供側が適切な対策をしてない場合には攻撃の入り口になり得るということでした。こわいね

### When the Spectrum Becomes the Battlefield: Defending Municipal IoT Under Jamming と Defending Critical National Infrastructure in a Hybrid Threat Landscape

最後の二つのセッションはウクライナの通信企業や政府のセキュリティ機関による、ロシアによる侵攻の影響に関する内容でした。普段システムを作るときに戦争のことは考えもしませんが、ウクライナのエンジニアの方はそれが現実問題として目の前にあり、特に生活インフラに関わる部分では重大だなと思いました。
戦時中や災害時など、いざというときに動くのは難しいので、日頃から冗長性と柔軟性を意識し、様々な事象に対して頑健な仕組みを作っていく必要があると思いました。

### ネットワーキングパーティー

一番難しかったです。人見知りなので、今までこういうときは知ってる人+知らない人で話してるところに行って輪に入れてもらうという作戦で乗り切っていましたが、今回はだれも知り合いがいなかったので、詰んでいました。何人かの方と話した後、心が折れて半分くらいの時間で帰りました。話してくださった方はありがとうございました。

## おわり

普段自分はセキュリティをそんなにやってる訳ではないですが、情報漏洩や脆弱性、サプライチェーン攻撃などでセキュリティが話題になっているタイミングで、最前線のいろんな話を聴けたのは良かったです。
普段からセキュリティの意識を高く持とうと改めて思いました。
